# Rock Paper Scissors Game

A fun and responsive **Rock Paper Scissors** browser game built with HTML, CSS, and JavaScript.

## Features

- Play against a computer that makes a random choice
- Rock, Paper, and Scissors game controls
- Win, loss, and draw score tracking
- Hand-shake animation before each result
- Reset button to start a new game
- Responsive design for mobile and desktop screens

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Choose Rock, Paper, or Scissors and play!
